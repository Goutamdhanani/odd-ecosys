# S00 side-effect boundary inventory

The machine-readable inventory at [s00-side-effect-inventory.json](s00-side-effect-inventory.json) enumerates the current marker-matched boundaries: 42 pipeline modules, three browser API modules including the Astra workbench, and `server.js`. Fourteen Phase 2 modules were added after the prior 33-row inventory. Their rows now include observed guards, destinations and current approval status alongside source hash, effect class and behavior test links. `pipeline/personalizer.js` no longer matches the static markers; it is retained in `retiredBoundaries` as a historical provider-call boundary for manual review. The executable `S00-B02` test discovers the current marker-matched module set, requires an exact inventory match, verifies each source hash and confirms every listed test file exists. Its pure negative probe adds a synthetic future adapter path to the discovered set and confirms it is reported missing.

Coverage includes provider/search/directory adapters, website and qualification HTTP/browser work, DNS and optional SMTP verification, configured model calls, outbound SMTP, inbound IMAP, CRM sync, Astra dispatch/connectors/research/source collection, local SQLite writes, filesystem/PDF output, auth/session and server API mutation boundaries. The inventory is a source boundary map; it does not mean an effect is authorized, enabled, or integration-tested. Test file presence is not a passing result. Required selected tests and exact outcomes are recorded in this candidate's `test-results.json`.

The marker scan is intentionally fail-closed for file changes: edits to listed boundary files require inventory re-review and hash refresh, while new marker-bearing pipeline modules fail the test until listed and linked to behavior evidence. The scan is not a semantic proof; code review remains necessary for aliases, dynamic imports, SDK defaults and side effects expressed without the known markers. No provider credential, live request, customer record or production database was read.
